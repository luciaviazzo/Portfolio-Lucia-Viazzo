LinkedUNQ - Plataforma Universitaria

Aplicación web full stack diseñada para conectar estudiantes de la Universidad Nacional de Quilmes con oportunidades laborales y académicas. El sistema permite a los estudiantes crear perfiles profesionales, buscar ofertas y postularse directamente.

Características principales

  • APIs REST modulares desarrolladas con NestJS y TypeScript
  • Frontend responsive con React y Tailwind CSS
  • Autenticación y autorización de usuarios
  • Sistema de búsqueda y filtrado de oportunidades
