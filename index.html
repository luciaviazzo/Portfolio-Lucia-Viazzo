LinkedUNQ - Plataforma Universitaria

LINKEDUNQ es una aplicación web full stack desarrollada en equipo como proyecto universitario, cuyo objetivo es conectar estudiantes de las carreras de informática de la Universidad Nacional de Quilmes (UNQ) con oportunidades laborales, pasantías y primeras experiencias profesionales en el área IT.

La plataforma permite a los estudiantes registrarse, crear su perfil profesional con sus habilidades y experiencia, y postularse a ofertas laborales publicadas por empresas. Por otro lado, los reclutadores pueden publicar búsquedas, visualizar perfiles de candidatos y gestionar las postulaciones recibidas.

Características principales

  • Desarrollo de APIs REST escalables con NestJS y TypeScript.
  • Implementación de autenticación y autorización basada en roles.
  • Modelado de datos y persistencia SQL mediante Prisma ORM.
  • Construcción de SPA responsive con React, Vite y Tailwind CSS.
  • Integración frontend–backend mediante consumo de APIs REST.
  • Implementación de testing automatizado en backend.
  • Arquitectura modular siguiendo buenas prácticas de clean code.
  • Organización del desarrollo con metodología Scrum.

ConcuConvolution – Procesamiento Concurrente de Imágenes

ConcuConvolution es una aplicación desarrollada en Java como proyecto academico grupal, cuyo objetivo es analizar el impacto de la programación concurrente en el rendimiento del procesamiento de imágenes mediante filtros de convolución.

La aplicación permite procesar imágenes de forma secuencial y concurrente, posibilitando la comparación de tiempos de ejecución y el análisis del impacto del paralelismo en términos de performance y escalabilidad.

La herramienta genera benchmarks automáticos a partir de las ejecuciones, cuyos resultados son posteriormente analizados mediante scripts en Python para visualizar y comparar el comportamiento de las distintas estrategias de ejecución.

Características principales

  • Procesamiento de imágenes mediante filtros de convolución (kernels 3x3 y 5x5).
  • Implementación de ejecución secuencial y concurrente para comparación de performance.
  • Desarrollo de un ThreadPool propio para la ejecución de tareas concurrentes.
  • Implementación de buffer circular thread-safe para la comunicación entre tareas.
  • Gestión de dependencias entre regiones de imagen para asegurar correctitud en la ejecución paralela.
  • Configuración dinámica de parámetros de ejecución mediante archivos externos.
  • Generación automática de benchmarks de rendimiento.
  • Scripts de análisis y visualización de resultados experimentales.

Bug Busters - Backend Persistencia Múltiple

Bug-Busters es un proyecto académico grupal desarrollado en Java, enfocado en aplicar buenas prácticas de desarrollo backend en un entorno similar al profesional. El sistema modela entidades paranormales (espíritus, médiums, santuarios y ubicaciones) y sus interacciones mediante una arquitectura en capas y una API REST.

Durante el desarrollo se integraron múltiples estrategias de persistencia, junto con testing automatizado, patrones de diseño y metodologías de trabajo colaborativo. El proyecto permitió fortalecer habilidades en diseño de software, modelado de dominio, integración de bases de datos SQL y NoSQL, y aplicación de principios SOLID y Clean Code.

Características principales

  • Arquitectura backend multicapa (Controller – Service – DAO – Model)
  • Desarrollo de API REST para gestión de entidades del dominio
  • Implementación de lógica de negocio y CRUD completo de entidades del dominio
  • Integración de múltiples estrategias de persistencia (SQL, MongoDB y Neo4J y Redis)
  • Aplicación de buenas prácticas de desarrollo (patrones de diseño, SOLID, Clean Code)
  • Testing automatizado con pruebas unitarias y de integración
  • Trabajo colaborativo utilizando Git, GitHub y GitFlow
